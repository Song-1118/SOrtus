## 一、产品概述

### 1.1 产品定位

SOrtus 是一款面向个人与小型团队的**本地优先立项管理桌面工具**。它以"立项"为核心单元，为不同类型的项目（编程开发、视频剪辑、日常待办）提供从立项采集、过程管理到验收跟踪的统一入口。

> 一句话定位：**用一个小工具管理您的立项。**

### 1.2 核心价值主张

- **一个工具管三类项目**：编程开发、剪辑、待办，统一立项体验，减少工具切换。
- **立项即沉淀**：立项时采集关键信息，项目全程信息集中留存、可回溯。
- **本地优先、隐私无忧**：纯本地运行，无后端、无账号、无数据上传。
- **纯净无商业化**：免费开源（MIT），无收费、无会员、无广告。
- **现代质感**：高斯模糊、圆角、动画，提供舒适愉悦的桌面体验。

### 1.3 产品边界

| 属于 SOrtus | 不属于 SOrtus |
| --- | --- |
| 三类立项的创建、查看、编辑、删除 | 团队协作/多人实时协同 |
| 立项信息的过程管理与进度跟踪 | 云端同步、远程接口、后端服务 |
| 数据本地存储与 `.json` 迁移 | 收费、会员、广告、内购 |
| Git 基础操作（提交/推送/回退） | 完整 IDE 功能、代码托管 |
| 到期提醒 | 企业级项目组合管理（PPM） |

### 1.4 产品类型与平台

- **类型**：Windows x64 桌面应用
- **形态**：开源、免费、本地单机
- **平台**：Windows 10 / 11 x64

## 二、目标用户与场景

### 2.1 用户画像

| 用户类型 | 典型特征 | 核心诉求 |
| --- | --- | --- |
| 独立开发者 / 编程学习者 | 经常启动新项目，使用 Git | 记录技术栈、开发规划、目标与验收标准，跟踪版本与进度 |
| 视频创作者 / 剪辑师 | 制作 Vlog、教程、微电影、纪录片 | 管理拍摄与剪辑进度、素材清单与素材文件夹 |
| 个人任务管理者 | 有日常任务与截止时间 | 快速录入待办、设置提醒、标记完成 |

### 2.2 典型使用场景

**场景一：编程开发者启动新项目**
> 小明要做一个新工具，他打开 SOrtus，选择"编程开发项目"，填入项目名、勾选技术栈（.NET/WPF）、写简介、关联本地项目文件夹、设定工期。开发过程中，他随时更新开发规划、记录验收标准、查看进度，并通过内置 Git 按钮提交代码。

**场景二：剪辑师筹备短片**
> 小红接到一个微电影项目，她在 SOrtus 选择"剪辑项目"，填主题、名字、目标时长、类型"微电影"、预计工期，之后在详情页跟踪拍摄进度与剪辑进度，管理素材清单并关联素材文件夹。

**场景三：个人管理待办**
> 小刚记下"周五前交报告"这一待办，设定完成时间并打开提醒，到期前应用会主动提醒他。完成后一键勾选。

## 三、产品目标与非目标

### 3.1 产品目标

1. **覆盖立项全流程**：支持立项创建到过程管理的完整闭环，不让用户再回到零散记录。
2. **信息集中可追溯**：所有立项信息与进度变化集中保存，可回溯、可复盘。
3. **降低使用门槛**：三类项目共用统一交互范式，上手即用，无需学习成本。
4. **保证数据主权**：数据完全留在本地，用户可随时导出带走。
5. **提供愉悦体验**：现代视觉与流畅动画提升使用意愿。

### 3.2 非目标（明确不做）

- 不预留任何远端接口，不开发后端服务器。
- 不做用户系统、登录、账号体系。
- 不做收费、会员、订阅、广告、内购。
- 不做跨设备云同步、多人协作。
- 不做代码编辑器、完整 Git 客户端、专业素材库等重功能。

### 3.3 成功指标（供参考）

| 指标 | 说明 |
| --- | --- |
| 功能覆盖率 | P0/P1 功能实现率 100% |
| 稳定性 | 主流程无阻断性缺陷 |
| 数据可靠性 | 导出/导入后数据完整一致，备份可恢复 |
| 视觉体验 | 模糊、主题、动画三项核心视觉特性通过验收 |
| 本地化 | 中英双语切换正常 |

## 五、详细功能需求

> 符号说明：`[]` 为非正文描述；`()` 为补充说明。

### 5.1 编程开发项目立项

#### 5.1.1 立项时采集（必填/选填）

| 字段 | 类型 | 说明 | 必填 |
| --- | --- | --- | --- |
| 项目名字 | 文本 | 项目显示名称 | 是 |
| 技术栈 | 选择 + 自定义 | 支持多选，可从预设中选择或自定义输入 | 是 |
| 简介 | 多行文本 | 项目简要说明 | 否 |
| 类型 | 选择 | 编程项目子类型 | 否 |
| 关联文件夹 | 路径选择 | 关联本地项目目录（远期支持关联 SSH） | 否 |
| 开发工期 | 日期范围 | 起止日期或预估工时 | 否 |

#### 5.1.2 立项后可管理

- 项目名称、技术栈、简介、类型、关联文件夹的编辑
- **开发规划**：里程碑、阶段计划的结构化记录
- **开发约束**：技术约束、编码规范、外部限制
- **开发目标**：项目要达成的目标
- **验收标准**：可量化的验收条件
- **Git 提交 / 推送 / 回退**：基于关联文件夹的 Git 仓库执行基础操作
- **项目版本**：版本号管理与展示
- **发行**：发行说明、发行包信息
- **开发进度**：百分比或阶段进度

### 5.2 剪辑项目立项

#### 5.2.1 立项时采集

| 字段 | 类型 | 说明 | 必填 |
| --- | --- | --- | --- |
| 项目主题 | 文本 | 作品主题 | 是 |
| 项目名字 | 文本 | 作品名称 | 是 |
| 目标时长 | 时长 | 成片目标时长 | 否 |
| 类型 | 选择 | Vlog / 教程 / 微电影 / 纪录片 / 自定义 | 是 |
| 预计工期 | 日期范围 | 预计完成时间 | 否 |

#### 5.2.2 立项后可管理

- 剪辑进度（百分比/阶段）
- 拍摄进度（百分比/阶段）
- 素材管理（素材名称、状态、备注、增删改查）
- 关联素材文件夹

### 5.3 待办类型立项

#### 5.3.1 立项时采集

| 字段 | 类型 | 说明 | 必填 |
| --- | --- | --- | --- |
| 任务 | 文本 | 待办描述 | 是 |
| 完成时间 | 日期时间 | 截止时间 | 是 |

#### 5.3.2 立项后可管理

- 是否完成（勾选切换完成状态）
- 提醒（到期提醒，支持当天/提前 N 分钟或小时）

### 5.4 数据与设置

#### 5.4.1 数据导出导入备份

- **导出**：支持全量导出所有立项、或单立项导出，格式为 `.json`，内容完整可校验。
- **导入**：从 `.json` 导入，提供覆盖当前数据或合并两种策略，导入前提示确认。
- **备份**：一键生成数据库备份文件。
- **恢复**：从备份文件恢复数据，恢复前二次确认并提示风险。

#### 5.4.2 高斯模糊

- 全局控件高斯模糊，强度可在设置中以滑块调节（如 0~N 档）。
- 设置实时生效并持久化，重启后保持用户设定。

#### 5.4.3 主题

- 至少提供两套主题（如浅色、深色），支持运行时一键切换。
- 切换后全局控件、窗口背景、文字颜色一致生效。

#### 5.4.4 多语言

- 前期支持**中文、英文**，所有可见界面文本走资源文件，不留硬编码。
- 运行时可切换语言，切换后即时生效。
- 预留**韩文、日文**扩展点，新增语言仅需补充资源文件。

### 5.5 交互规则

- 新建/编辑操作提供明确的保存与取消入口，未保存变更应有提示。
- 删除、导入覆盖、恢复等高风险操作均需二次确认。
- 长列表支持搜索与筛选，操作结果有反馈（成功提示 / 错误提示）。
- 空状态、加载状态、错误状态均有友好界面提示。

## 六、用户体验与界面要求

### 6.1 视觉风格

- **控件高斯模糊**：关键面板/弹窗/背景使用高斯模糊，营造层次感。
- **圆角**：按钮、输入框、卡片、窗口等控件采用圆角设计。
- **现代动画**：页面切换、弹窗进出、列表项增删使用平滑过渡动画。
- **平滑动画**：进度条、数值变化、状态切换使用缓动动画，避免生硬跳变。

### 6.2 主要界面

| 界面 | 核心内容 |
| --- | --- |
| 主窗口 / 立项列表 | 全部立项概览、类型筛选、搜索、新建入口 |
| 立项向导 | 分类型采集立项时信息 |
| 立项详情页 | 立项后字段的分区管理（基础信息 / 过程管理 / Git / 进度） |
| 设置页 | 高斯模糊强度、主题、语言、数据导出导入备份 |
| 提醒通知 | 待办到期提醒弹窗或通知 |

### 6.3 可用性要求

- 关键操作支持键盘可达（Tab 顺序合理，主要按钮可回车确认）。
- 文本与背景对比度满足基本可读性。
- 窗口支持常规缩放，内容区可滚动，不出现内容被截断且无入口的情况。

## 八、里程碑规划

### 8.1 阶段划分

| 里程碑 | 名称 | 关键交付 | 阶段 |
| --- | --- | --- | --- |
| P1 | 项目脚手架与基础设施 | 解决方案、分层架构、SQLite、主窗口骨架 | 第 1 阶段 |
| P2 | 编程类型 MVP | 编程立项闭环（创建—管理—进度） | 第 2 阶段 |
| P3 | 剪辑与待办类型 | 剪辑、待办两类立项的完整功能 | 第 3 阶段 |
| P4 | 视觉与本地化 | 模糊、主题、动画、中英双语 | 第 4 阶段 |
| P5 | 数据迁移与 Git | 导出导入备份、Git 操作、版本发行 | 第 5 阶段 |
| P6 | 收尾与发布 | 提醒、测试、文档、打包、MIT 合规 | 第 6 阶段 |

### 8.2 各阶段要点

- **P1**：搭建 `.NET 10 LTS + C# 14 + WPF` 工程，确立 MVVM 分层，完成 SQLite 接入与表结构迁移。
- **P2**：实现编程开发项目的立项向导、列表、详情与立项后字段管理，打通主闭环。
- **P3**：补齐剪辑项目（拍摄/剪辑进度、素材、素材文件夹）与待办（完成状态、提醒）两类立项。
- **P4**：落地高斯模糊（可调）、至少两套主题、圆角动画、中英文切换及韩日扩展预留。
- **P5**：完成 `.json` 导出导入、备份恢复、编程类型 Git 提交/推送/回退、版本与发行管理。
- **P6**：实现待办提醒触发，完成集成测试与回归，完善文档并打包发布。

## 九、验收标准

### 9.1 总验收标准

> 产品整体验收通过需同时满足以下标准。

1. **功能完整**：三类立项（编程 / 剪辑 / 待办）的 P0、P1 需求全部可用，立项创建到过程管理的闭环完整。
2. **技术符合**：技术栈为 `.NET 10 LTS + C# 14 + WPF + SQLite`，Windows x64 平台，可成功构建运行。
3. **数据正确**：CRUD 操作准确无误，SQLite 持久化正常，重启后数据不丢失。
4. **数据可迁移**：`.json` 导出内容完整合法、可重新导入；备份可恢复且数据一致。
5. **视觉达标**：高斯模糊（强度可调）、圆角、至少两套主题、现代动画与平滑动画均已实现，交互流畅。
6. **多语言达标**：中英文切换正常，全部文本走资源；韩文、日文扩展点已预留。
7. **约定遵守**：无远端接口、无后端、无收费/会员/广告，纯本地运行。
8. **Git 可用**（编程类型）：在合法 Git 仓库路径下提交/推送/回退可用，失败有明确提示。
9. **质量稳定**：主流程无阻断性缺陷，关键业务有测试覆盖，崩溃有日志。
10. **可发布**：可打包为 x64 安装包/便携版，在 Windows 10/11 正常运行。
11. **文档许可**：PRD、开发文档、使用说明齐全；仓库含 `LICENSE`（MIT）。

### 9.2 各阶段验收标准

#### P1 验收标准

- 工程可成功编译运行，主窗口与导航框架可见。
- 分层架构目录清晰，职责明确。
- 首次运行自动创建 SQLite 数据库与立项基表，迁移机制可用。

#### P2 验收标准

- 可走完编程项目的完整立项流程（向导采集全部立项时字段）。
- 立项列表可展示、筛选、搜索。
- 详情页可编辑立项后字段（开发规划/约束/目标/验收标准/进度）。
- 数据写入后重启不丢失。

#### P3 验收标准

- 可走完剪辑项目的完整立项与管理（进度、素材、素材文件夹）。
- 可走完待办类型的完整立项与管理（完成状态、提醒设置）。
- 三类立项在同一列表正确区分、差异化展示编辑，互不干扰。

#### P4 验收标准
