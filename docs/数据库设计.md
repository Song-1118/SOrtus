# SOrtus 数据库设计

> 版本：v1.0
> 文档类型：数据库设计（Schema & Migration）
> 适用范围：SOrtus 数据访问层、迁移机制
> 最后更新：2026-10-22
> 维护者：SOrtus 研发

## 一、总体说明

- **引擎**：SQLite（单文件，本地优先），通过 `Microsoft.Data.Sqlite` 访问。
- **文件位置**：`%LocalAppData%/SOrtus/soctus.db`（运行期生成，不入库）。
- **迁移机制**：自增版本号表 `SchemaVersion`，启动时按未应用脚本顺序执行；脚本文件名含版本号，幂等，可重复执行不报错（见 `src/SOrtus/Migrations/`）。
- **命名规范**（规范 5.3）：表名/字段名大驼峰、单数；主键 `Id`；外键 `<目标表>Id`；时间字段以 `At` 结尾；布尔以 `Is/Has/Can` 开头。

## 二、当前表结构（v0001）

### 2.1 SchemaVersion

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Version | INTEGER PK | 已应用的迁移版本号 |
| AppliedAt | TEXT | 应用时间（ISO8601） |

### 2.2 Project（立项基表，承载三类立项）

立项类型通过 `Type` 区分；差异化字段在 MVP 阶段先以编程类型所需列落地，剪辑/待办类型在 1.1/1.2 版本通过新增列或 JSON 扩展列补齐（破坏性变更随大版本迁移）。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Id | INTEGER PK AUTOINCREMENT | 立项唯一标识 |
| Name | TEXT NOT NULL | 名称（编程：项目名字 / 剪辑：作品名 / 待办：任务） |
| Type | INTEGER NOT NULL | 立项类型（0=Programming,1=Clip,2=Todo） |
| Status | INTEGER NOT NULL | 状态（0=Planning,1=Active,2=Completed,3=Archived,4=OnHold） |
| CreatedAt | TEXT NOT NULL | 创建时间 |
| UpdatedAt | TEXT NOT NULL | 更新时间 |
| TechStack | TEXT | 技术栈（`;` 分隔，可多选+自定义） |
| Summary | TEXT | 简介 |
| SubType | TEXT | 编程子类型 / 剪辑类型（Vlog/教程/微电影/纪录片/自定义） |
| FolderPath | TEXT | 关联文件夹（编程：项目目录 / 剪辑：素材文件夹） |
| ScheduleStart | TEXT NULL | 工期起（编程）/ 预计工期起 |
| ScheduleEnd | TEXT NULL | 工期止 / 预计工期止 |
| DevPlan | TEXT | 开发规划（编程）/ 拍摄进度（剪辑，后续扩展） |
| Constraints | TEXT | 开发约束（编程） |
| Goals | TEXT | 开发目标（编程） |
| AcceptanceCriteria | TEXT | 验收标准（编程） |
| ProgressPercent | REAL | 进度百分比（0~100） |

> 说明：MVP（0.1.0）仅开放编程类型立项；剪辑/待办相关字段在后续迁移中按类型逐步补齐，保持历史数据不丢失。

## 四、迁移约定（规范 9.8 / 14 红线）

- 每次结构变更必须新增 `vNNNN_*.sql`，文件名含版本号。
- 破坏性变更（删字段、改字段含义）必须在大版本号递增时做，并提供迁移指引。
- 脚本保持幂等（`CREATE TABLE IF NOT EXISTS`），升级时按未应用版本顺序执行。
- 禁止跳过迁移脚本直接改表（违反规范红线第 9 条）。
