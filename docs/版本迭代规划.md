## 一、文档说明

### 1.1 用途

本文档是 SOrtus 的**开发专用版本规划**，规定每个版本的：

- 版本号与定位
- 本期新增 / 变更 / 修复范围（Backlog）
- 技术实现要点
- **本版本专属验收标准**（可逐条勾选）

### 1.2 与里程碑文档的关系

前版《开发文档》的 M1–M6 里程碑对应到本文档的版本映射如下：

| 里程碑            | 对应版本                   | 说明                 |
| -------------- | ---------------------- | ------------------ |
| M1 脚手架与基础设施    | MVP（0.1.0）             | 工程骨架 + 架构 + SQLite |
| M2 编程类型 MVP 闭环 | MVP（0.1.0）             | 首个可演示的可用版本         |
| M3 剪辑与待办类型     | 1.1（0.2.0）+ 1.2（0.3.0） | 补齐三类立项             |
| M4 视觉与体验       | 1.3（0.4.0）             | 模糊、主题、动画、多语言       |
| M5 数据迁移与 Git   | 1.4（0.5.0）+ 1.5（0.6.0） | 导出导入备份、Git、版本发行    |
| M6 收尾与发布       | 1.0.0 正式版              | 提醒、测试、打包、MIT 合规    |

### 1.3 版本状态定义

- **开发中（WIP）**：代码分支开发阶段
- **提测（In QA）**：研发自测通过，移交测试
- **已验收（Accepted）**：本版本验收标准全部通过
- **已发布（Released）**：打 Tag、打包、对外发布

### 1.4 优先级约定

- **P0**：本版本必须完成，否则版本不可验收
- **P1**：重要功能，应尽量完成，未完成需记录遗留
- **P2**：可顺延至下个版本

## 三、MVP 版本（0.1.0）

### 3.1 版本定位

首个可运行的开发版本，目标是打通"工程骨架 + 架构 + 编程开发项目完整闭环"，让团队能看到并演示一个真实可用的立项流程。

### 3.2 本期范围

#### 新增（New）

- [ ] 搭建 `.NET 10 LTS + C# 14 + WPF` 解决方案，目标框架 `net10.0-windows`
- [ ] 落地分层架构：View / ViewModel / Service / Repository
- [ ] 接入 SQLite，完成立项基表与表结构迁移机制
- [ ] 主窗口骨架与基础导航框架
- [ ] 编程开发项目**立项向导**：项目名字、技术栈（选择+自定义）、简介、类型、关联文件夹、开发工期
- [ ] 立项列表：展示、按类型/状态筛选、搜索
- [ ] 立项详情页：基础字段查看与编辑
- [ ] 立项后字段管理：开发规划、开发约束、开发目标、验收标准
- [ ] 开发进度管理（百分比/阶段）
- [ ] 构建脚本与版本号管理

#### 视觉基础（New）——全局样式与高斯模糊组件化

- [ ] 新增 `src/SOrtus/Resources/Styles/` 全局样式资源字典（`Colors.xaml` / `Sizes.xaml` / `Brushes.xaml` / `Animations.xaml` / `Controls.Base.xaml` / `Styles.xaml` 总入口）与 `Resources/Themes/` 主题字典（`Light.xaml` / `Dark.xaml` / `Theme.xaml`）
- [ ] 在 `Sizes.xaml` 定义模糊半径档位：`BlurRadiusSubtle(6) / Normal(12) / Strong(20) / Overlay(30)`，禁止在页面内硬编码模糊半径
- [ ] 新增 `src/SOrtus/Controls/BlurPanel.cs`，提供 `EnableBlur / BlurRadius / OverlayOpacity / Background` 四个附加属性
- [ ] `BlurPanel` 内部构建"背景模糊层（VisualBrush + BlurEffect）+ 覆盖层"两层结构，使用 `Grid` 承载，保证模糊只作用于背景、不模糊文字与子控件
- [ ] 模糊覆盖层色值、透明度统一通过 `DynamicResource` 引用主题画刷，支持浅色/深色切换自动响应
- [ ] 主窗口、编程立项向导、详情页、列表容器等核心界面接入 `BlurPanel`，页面 XAML 内不得出现 `<BlurEffect>` 内联标签
- [ ] 模糊只作用于静态层，静态层启用 `CacheMode="BitmapCache"`；禁止给 `ListView`/`DataGrid` 的列表项单独套模糊，禁止把动画作用在 `BlurEffect.Radius` 上逐帧重算

#### 变更（Changed）

- 无（首个版本）

#### 修复（Fixed）

- 无（首个版本）

### 3.3 技术要点

- 数据模型：立项基类 `Project` + 编程派生实体，差异化字段建议用 JSON 列承载，便于扩展
- MVVM：命令绑定、属性通知、`INotifyPropertyChanged`
- 导航：简单的内容区切换或导航服务，不引入重型框架
- 数据迁移：自增版本号表，启动时自动执行待应用的迁移脚本

> 逐条勾选，全部通过方可进入"已验收"。

## 六、1.3 版本（0.4.0）

### 6.1 版本定位

全面升级视觉与交互体验，落地高斯模糊组件化、主题、动画、多语言四大特性，是产品"现代质感"与"视觉代码规范化"的定型版本——后续所有视觉开发均以全局资源字典与 `BlurPanel` 组件为准，禁止页面内另写模糊实现。

### 6.2 本期范围

#### 新增

- [ ] 控件高斯模糊组件化：新增 `BlurPanel` 自定义控件，通过附加属性挂载，页面零内联模糊代码（详见 `项目开发规范.md` 第七章）
- [ ] 全局样式收归资源字典：`Styles/Blur.xaml`、`Brushes.xaml`、`Sizes.xaml`、`Animations.xaml`，模糊半径用命名档位统一定义
- [ ] 高斯模糊强度可全局调节（设置项 + 实时生效 + 持久化），调节档位强度系数，改一处全应用生效
- [ ] 至少两套主题（浅色/深色），运行时一键切换，主题字典整本替换、资源键一一对应
- [ ] 控件圆角、阴影样式统一
- [ ] 现代动画与平滑动画（页面切换、弹窗进出、列表增删、进度/数值过渡）
- [ ] 多语言框架接入，完成中文 + 英文资源
- [ ] 预留韩文、日文资源扩展点
- [ ] 设置页（模糊强度、主题、语言）

#### 变更

- [ ] 全局样式统一收归资源字典，消除硬编码颜色

#### 修复

- [ ] 修复 0.3.0 版本遗留缺陷

### 6.3 技术要点

- **高斯模糊（复用 MVP 的 `BlurPanel`，本版不做重建）**：
  - MVP 已完成 `BlurPanel` 与全局样式资源字典（`Styles/Styles.xaml`、`Styles/Blur.xaml`、`Brushes.xaml`、`Sizes.xaml`、`Animations.xaml`）以及主题字典，本版本直接复用
  - 本版新增：将模糊档位接入**设置页**，提供 Subtle/Normal/Strong/Overlay 档位，用户调节后实时作用于全局所有模糊控件并持久化；同时补齐浅色/深色两主题下所有控件的覆盖层色值、透明度、画刷，保证资源键一一对应
  - 性能红线沿用规范第七章 7.7：默认半径不超过 20；禁止给 `ListView`/`DataGrid` 每一项单独套模糊；禁止动画改 `BlurEffect.Radius` 逐帧重算；静态层加 `BitmapCache`；禁止同时开启 `AllowsTransparency=true` 与大范围模糊
- **圆角、动画一并全局化**：`Sizes.xaml` 定义 `CornerRadiusSmall/Medium/Large/Pill`；进入/退出/悬浮 Storyboard 集中在 `Animations.xaml`，优先用无 `x:Key` 的隐式样式减少页面样板代码
- 多语言：`IStringLocalizer` + `.resx`，所有可见文本走资源

- 本版本 P0 验收项 **100% 通过**，版本方可"已验收"
- P1 项未全部完成需记录遗留并评估，不得静默跳过

- 研发自测：开发者按验收标准逐条执行并打勾

### 10.4 缺陷等级

| 等级 | 定义 | 处理要求 |
| --- | --- | --- |
| 阻断（Blocker） | 主流程不可用、崩溃、数据丢失 | 必须本版本修复 |
| 严重（Major） | 核心功能异常但可绕过 | 本版本修复或书面遗留 |
